# Живий архів: структура та запуск

- `npm run dev` — локальна розробка.
- `npm run build` — перевірка TypeScript, клієнтська збірка та формування HTML для всіх сторінок.
- `node scripts/verify-built-pages.mjs` — перевірка наявності текстів без JavaScript, мовних метаданих і внутрішніх посилань.
- `npm run preview` — перевірка зібраного статичного сайту.

## Мови й адреси

`/uk/` та `/en/` — подорожі; `/uk/archive/` та `/en/archive/` — колекції; `/<мова>/archive/<slug>/` — окремі матеріали. Перемикач мови у статті веде до відповідної статті. Дев’ять матеріалів мають окремо підготовлені українські й англійські тексти.

## SEO перед публікацією

Задайте справжню адресу сайту через `SITE_URL` під час збірки. Наприклад у PowerShell: `$env:SITE_URL='https://ваш-реальний-домен'; npm run build`. Значення — справжній домен без шляху. Без нього збірка використовує локальну адресу й забороняє індексацію в robots.txt.

Готові HTML, canonical, hreflang, Open Graph, Article/CollectionPage JSON-LD і sitemap.xml формуються автоматично. Публікуйте вміст `dist`. Хостинг має віддавати файли `/<мова>/archive/<slug>/index.html` за відповідними адресами, зберігати каталоги та використовувати `404.html` зі статусом 404. Не налаштовуйте загальне перенаправлення всіх маршрутів на кореневий index.html.

## Контент та джерела

Дані — `src/archive/content.ts`. Зображення — `public/images`; походження — `ASSETS.md` і `SOURCES.md`. Колажі самвидаву й папки — явно позначена інтерпретація, не факсиміле. Обставини смерті подані з розрізненням фактів і версій; матеріал Суспільного позначений як повідомлення 2021 року.

Нотатки й збережені матеріали залишаються в браузері. Нові сторінки не вимагають реєстрації. Пошук працює по назвах, роках та описах.

## Взаємодія з аркушами
Аркуш відкриває повний матеріал у вікні читання: розділи, запитання, джерела та окрема адреса статті. Нижній дубль опису прибрано. Кругове перетягування працює безпосередньо з кутом рулетки; після відпускання вона доводиться до найближчого аркуша. Є стрілки й керування клавіатурою.
