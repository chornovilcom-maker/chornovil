# Чорновіл — живий архів

Інтерактивний біографічний сайт про В’ячеслава Чорновола. Українська та англійська версії, хронологія, інтерактивні матеріали й архів статей із джерелами.

## Запуск

Потрібен Node.js 22 або новіший.

```sh
npm ci
npm run dev
```

Локальна адреса: http://localhost:5173/uk/. Англійська версія: /en/.

## Збірка й публікація

```sh
npm run build
node scripts/verify-built-pages.mjs
npm run preview
```

Для хостингу використовуйте папку `dist`. Збірка генерує 24 HTML-сторінки, мовні метадані та sitemap. Перед публікацією задайте змінну середовища `SITE_URL` із повною адресою сайту (без кінцевого слеша). Без цієї змінної індексація пошуковиками вимкнена.

Наприклад, у налаштуваннях хостингу: команда збірки `npm run build`, папка результату `dist`, змінна `SITE_URL=https://your-domain.example`.

Завантаження коду на GitHub саме по собі не публікує сайт. Хостинг налаштовується окремо; маршрути `/uk/`, `/en/` і сторінки архіву мають обслуговувати відповідні `index.html`.
