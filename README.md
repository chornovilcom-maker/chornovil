# Чорновіл — живий архів

Інтерактивний біографічний сайт про В’ячеслава Чорновола. Українська та англійська версії, хронологія, інтерактивні матеріали й архів статей із джерелами.

## Запуск

Потрібен Node.js 22 або новіший.

```sh
npm ci
npm run dev
```

Локальна адреса: http://localhost:5173/uk/. Англійська версія: /en/.

## Збірка й публікація

```sh
npm run build
node scripts/verify-built-pages.mjs
npm run preview
```

На Vercel конфігурація береться з `vercel.json`: збірка `npm run build` і перевірка HTML, результат `dist`. Основний домен — **https://chornovil.com**, стандартний origin SEO-метаданих. За потреби його можна перевизначити змінною `SITE_URL`.

У production дозволена індексація. Для Vercel Preview або `SEO_NOINDEX=1` генератор створює `Disallow: /` та `noindex`. Не встановлюйте `SEO_NOINDEX=1` у production. Метадані й повний текст усіх статей присутні у вихідному HTML без JavaScript.

`/` перенаправляється на `/uk/`; `www.chornovil.com` — на основний домен, коли DNS для www буде налаштовано. Невідомі адреси мають повертати справжній HTTP 404: глобальний SPA-rewrite на головну не потрібен.

### Домен і пошук

1. Vercel → Project → Settings → Domains: `chornovil.com` має бути прив’язаний до production. Для `www.chornovil.com` додайте домен і CNAME, **точне значення якого показує Vercel для цього проєкту**.
2. DNS налаштовується у поточного DNS-провайдера. Не змінюйте MX/TXT для пошти. Наявний A-запис основного домену перевірено: `216.198.79.1` (22.10.2026). Поширення записів на різні резолвери відбувається поступово.
3. Після публікації перевірте `/robots.txt`, `/sitemap.xml`, `/uk/`, `/en/`, статтю архіву й невідому адресу. Canonical має починатися з `https://chornovil.com`, а не localhost.
4. Додайте Domain property `chornovil.com` у Google Search Console, підтвердьте власність наданим Google TXT-записом і подайте `https://chornovil.com/sitemap.xml`. Перевірте головну в URL Inspection. Унікальний код підтвердження видає Google, його не можна вигадувати.
5. SEO не гарантує позицію №1. Потрібні перевірені змістовні матеріали, робота з джерелами та природні згадки й посилання. Не додавайте приховані ключові слова, фальшиві відгуки або вигадані дані в schema.
